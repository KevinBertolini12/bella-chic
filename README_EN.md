# ✂️ Bella & Chic — SaaS Management Platform for Salons & Barbershops

> Full multi-tenant SaaS platform for online booking, customer management, financial control, and service management designed for beauty and aesthetics professionals.

---

## 📌 About the Project

**Bella & Chic** was created to streamline online booking and operational management for beauty salons, barbershops, and independent aesthetic professionals. The platform allows customers to schedule appointments online 24/7, while business owners monitor schedules, revenue, and reports in real time.

### 🚀 Key Features

- **24/7 Online Booking:** Intuitive client interface to choose services, staff members, and available time slots.
- **Multi-Tenant Admin Panel:** Comprehensive management of business units, team members, commissions, and working hours.
- **Financial Module & CRM:** Customer appointment history, cash flow management, and performance analytics.
- **Service Integrations:** Support for automated notifications and appointment confirmations.

---

## 🛠️ Tech Stack

- **Front-end:** React, TypeScript, Tailwind CSS, Vite
- **Back-end & Serverless:** Node.js, Express, Firebase (Firestore & Auth)
- **Infrastructure & Deployment:** PM2 (Ecosystem), Bash Scripts, Contabo Linux VPS

## 💻 How to Run the Project Locally

```bash
# Clone the repository
git clone [https://github.com/KevinBertolini12/bella-chic.git](https://github.com/KevinBertolini12/bella-chic.git)

# Navigate to the project directory
cd bella-chic

# Install dependencies
npm install

# Start the development server
npm run dev
```
