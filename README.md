# ✂️ Bella & Chic — Plataforma SaaS de Gestão para Salões e Barbearias

> Sistema multiempresa (multi-tenant) completo para agendamento online, gestão de clientes, controle financeiro e organização de serviços para profissionais da beleza e estética.

---

## 📌 Sobre o Projeto

O **Bella & Chic** foi desenvolvido para resolver as dores de agendamento e gestão operacional de salões de beleza, barbearias e profissionais autônomos. A plataforma permite que clientes realizem agendamentos online de forma autônoma enquanto os gestores acompanham agenda, faturamento e relatórios em tempo real.

### 🚀 Principais Funcionalidades

- **Agendamento Online 24/7:** Interface intuitiva para clientes escolherem serviços, profissionais e horários disponíveis.
- **Painel Administrativo Multiempresa:** Gestão completa de unidades, colaboradores, comissões e horários de atendimento.
- **Módulo Financeiro & CRM:** Histórico de atendimentos por cliente, controle de caixa e relatórios de desempenho.
- **Integração de Serviços:** Suporte a notificações e rotinas automatizadas para confirmação de agendamentos.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React, TypeScript, Tailwind CSS, Vite
- **Back-end & Serverless:** Node.js, Express, Firebase (Firestore & Auth)
- **Infraestrutura & Deploy:** PM2 (Ecosystem), Bash Scripts, Contabo Linux VPS

---

## 💻 Como Executar o Projeto Localmente

```bash
# Clonar o repositório
git clone [https://github.com/KevinBertolini12/bella-chic.git](https://github.com/KevinBertolini12/bella-chic.git)

# Entrar na pasta do projeto
cd bella-chic

# Instalar as dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```
